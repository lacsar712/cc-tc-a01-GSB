# 隧道收敛测缝台

测量员**先把断面坐标钉进坐标册，再报送收敛毫米值**，钉桩登记与报送必须同一次提交完成。
接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

## 钉桩规则

1. **进队先钉桩**：报送断面时必须同时给出断面号与坐标；坐标钉进坐标册后收敛读数才进入待认领。
2. **没钉就报 → 整份退回**：坐标留空直接报送，不进认领，单据置为「退回」并写明 **还没钉桩**，同时该断面进入专页「待钉清单」。
3. **坐标快照**：钉桩成功的瞬间把坐标抄进本单据（`coordinate_snapshot`）。此后在专页改坐标只更新坐标册现值，**绝不回写任何单据快照，也不改动已办结结论**。
4. **钉桩 + 报送同一事务**：任一缺失视为没做完，不产生半成品单据。
5. **抢桩唯一**：同一桩号坐标册上只留一档（数据库唯一约束 + 行锁）。两人抢同一新桩号，一单胜出、另一单立刻 `409` 作废。
6. **权限**：测量员（writer）可钉桩、改坐标、报送；巡检员（reader）可查看坐标册与单据坐标，但不能钉桩、改坐标或报送。

## 页面

页眉导航分两页：

- **钉桩专页**：① 待钉清单　② 已钉档案（断面坐标册，可改现值）　③ 退单原因；以及「钉桩并报送」表单（同一次提交）。
- **断面总表**：只读展示全部单据，含钉桩时抄入的**坐标快照**、状态、结论。坐标不在总表登记（禁止只在末列挂坐标）。

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | `/api/auth/login` | 公开 | 登录换 JWT |
| GET  | `/api/stakes` | 登录 | 断面坐标册（已钉档案） |
| PATCH| `/api/stakes/{id}` | 测量员 | 只改册上坐标，不动单据快照/结论 |
| GET  | `/api/logs` | 登录 | 全部单据（含坐标快照、退回原因） |
| POST | `/api/submissions` | 测量员 | **钉桩 + 报送同一事务**；缺坐标 `202` 退回，抢桩负方 `409` |

单据 `status`：`pending`（待认领）/ `done`（已办结）/ `returned`（退回，不参与认领）。

## 技术栈

## 验收场景

1. **甲断面**：填断面号「甲」、坐标 `0.3`、收敛 `1.2`，一次提交 → 钉桩成功、坐标 `0.3` 抄进单据、进「待认领」，随后办结为「合格」。
2. **乙断面**：坐标留空直接报收敛 → 被挡回，专页退单原因写明「还没钉桩」，断面进待钉清单，永不被认领。
3. **办结后**：在专页把甲的坐标改成别的值，再打开那份办结单——坐标仍为 `0.3`，结论不变。
4. **抢桩**：两人并发提交同一新桩号，只成一单，另一单立刻失败。
